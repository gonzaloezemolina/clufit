# 04 - AI Blueprint

# Objetivo

Este documento define el funcionamiento de Argus, el sistema de inteligencia artificial de Clufit.

Argus representa el cerebro del producto.

Su función es comprender el comportamiento del usuario, detectar oportunidades de mejora y generar recomendaciones inteligentes que ayuden a progresar.

Argus nunca reemplaza al usuario.

Argus acompaña.

---

# Objetivos de Argus

- Comprender al usuario.
- Detectar patrones.
- Detectar procrastinación.
- Comprender el contexto.
- Recomendar mejoras.
- Detectar oportunidades.
- Motivar.
- Explicar cada recomendación.

---

# Qué puede hacer

Argus puede:

- Analizar hábitos.
- Analizar entrenamientos.
- Analizar recuperación.
- Analizar nutrición.
- Analizar productividad.
- Analizar disciplina.
- Analizar progreso.
- Analizar sincronizaciones.
- Analizar retos.
- Detectar patrones.
- Crear recomendaciones.
- Crear insights.
- Proponer retos.
- Explicar decisiones.

---

# Qué NO puede hacer

Argus nunca podrá:

- Modificar rutinas automáticamente.
- Modificar objetivos.
- Modificar hábitos.
- Aceptar retos.
- Cambiar configuraciones.
- Compartir información privada.
- Tomar decisiones por el usuario.

Toda acción importante requiere confirmación.

---

# Filosofía

Argus observa.

Argus aprende.

Argus recomienda.

El usuario decide.

---

# Fuentes de información

Argus obtiene información desde:

- Dashboard

# Context Engine

Argus utiliza el Context Engine para comprender qué está ocurriendo en tiempo real.

Ejemplos:

- El usuario está entrenando.
- El usuario está durmiendo.
- El usuario acaba de terminar un entrenamiento.
- El usuario lleva varias horas sin actividad.
- El usuario se encuentra en horario laboral.
- El usuario está utilizando excesivamente el teléfono.

El contexto modifica las recomendaciones.

---

# Procrastination Engine

Uno de los principales objetivos de Argus es medir la procrastinación.

Variables consideradas:

- Tiempo en redes sociales.
- Tiempo de pantalla.
- Objetivos pendientes.
- Horarios habituales.
- Tiempo de entrenamiento.
- Tiempo de descanso.
- Frecuencia de interrupciones.
- Constancia.

Resultado:

Procrastination Score

Argus nunca juzga.

Simplemente identifica oportunidades de mejora.

---

# Recommendation Engine

Argus genera recomendaciones personalizadas.

Ejemplos:

- Cambiar horario de entrenamiento.
- Dormir más.
- Reducir tiempo en redes.
- Aumentar hidratación.
- Mantener una racha.
- Ajustar frecuencia de entrenamiento.
- Iniciar un nuevo reto.

Cada recomendación incluye una explicación.

---

# Synchronization Intelligence

Cuando existe un compañero sincronizado, Argus analiza la dinámica entre ambos.

Ejemplos:

- Ambos mejoran.
- Ambos bajaron el rendimiento.
- Uno perdió disciplina.
- Uno puede motivar al otro.

Ejemplo de insight:

"Gonza viene entrenando con mayor constancia esta semana. Es un buen momento para entrenar juntos y recuperar la racha."

---

# Challenge Intelligence

Argus analiza los retos activos.

Puede:

- Detectar abandono.
- Detectar ventajas.
- Detectar empates.
- Detectar oportunidades.

También puede sugerir nuevos retos.

Nunca los crea automáticamente.

---

# Notification Intelligence

Argus decide cuándo una notificación aporta valor.

Evita enviar recordatorios innecesarios.

Prioriza:

- contexto
- relevancia
- momento adecuado

---

# Explicabilidad

Toda recomendación deberá responder:

- ¿Qué detecté?
- ¿Qué información utilicé?
- ¿Por qué lo recomiendo?
- ¿Qué beneficio puede generar?

El usuario debe entender el razonamiento de Argus.

---

# Personalidad

Argus comunica de forma:

- Cercana.
- Clara.
- Positiva.
- Motivadora.
- Directa.

Nunca utiliza un tono agresivo o culpabilizador.

---

# Ejemplos

Fitness

"Detecté que llevás tres semanas utilizando la misma rutina. Podría ser un buen momento para realizar algunos cambios."

---

Productividad

"Hoy aumentó tu tiempo en redes sociales durante la mañana. Esto impactó en tu índice de procrastinación."

---

Recuperación

"Dormiste menos que tu promedio habitual. Considerá priorizar el descanso antes del próximo entrenamiento."

---

Sincronización

"Gonza mantiene una mejor racha esta semana. Entrenar juntos podría ayudarte a recuperar consistencia."

---

Retos

"Ambos están muy cerca de completar el reto de 30 entrenamientos. Solo quedan dos sesiones."

---

# Integración con el producto

Argus participa en:

- Dashboard
- Objetivos
- Productividad
- Disciplina
- Fitness
- Recuperación
- Nutrición
- Retos
- Notificaciones
- Sistema de Sincronización

Es el único sistema presente en toda la aplicación.

---

# Evolución futura

En versiones futuras Argus podrá:

- Aprender preferencias del usuario.
- Priorizar recomendaciones.
- Detectar hábitos emergentes.
- Comprender tendencias de largo plazo.
- Adaptar automáticamente su comunicación.

Siempre respetando el principio de que el usuario mantiene el control.

---

# Decisions

## Decision 001

Argus nunca toma decisiones automáticamente.

---

## Decision 002

Toda recomendación debe ser explicable.

---

## Decision 003

El contexto tiene prioridad sobre reglas fijas.

---

## Decision 004

La procrastinación es una de las métricas centrales de Argus.

---

## Decision 005

Cuando exista una sincronización activa, Argus analizará tanto al individuo como a la dinámica entre ambos.

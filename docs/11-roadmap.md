# 11 - Product Roadmap

# Objetivo

Definir la evolución de Clufit a lo largo del tiempo.

El roadmap representa la visión del producto y las prioridades de desarrollo. No es un backlog ni una lista de tareas.

---

# Filosofía

Cada versión debe aportar valor real al usuario.

No se lanzarán funcionalidades incompletas por cumplir una fecha.

La prioridad siempre será:

1. Calidad.
2. Experiencia de usuario.
3. Escalabilidad.

# Criterios de Lanzamiento

Una versión solo podrá publicarse si:

- Cumple los objetivos definidos.
- No introduce deuda técnica crítica.
- Mantiene el rendimiento esperado.
- Supera las pruebas funcionales.
- La experiencia de usuario está validada.

---

# North Star del Roadmap

Cada nueva versión debe aumentar alguna de estas métricas:

- Retención.
- Consistencia.
- Entrenamientos completados.
- Objetivos cumplidos.
- Retos creados.
- Retos completados.
- Usuarios sincronizados.

Nunca se desarrollarán funcionalidades que no aporten valor medible.

---

# Decisions

## Decision 001

El MVP será exclusivamente para iOS.

---

## Decision 002

La sincronización entre usuarios es el diferencial principal del producto y tendrá prioridad sobre nuevas funcionalidades.

---

## Decision 003

La comunidad no formará parte del MVP.

---

## Decision 004

La plataforma web para usuarios queda postergada hasta validar el producto mobile.

---

## Decision 005

Cada versión deberá validar una hipótesis concreta antes de avanzar a la siguiente.

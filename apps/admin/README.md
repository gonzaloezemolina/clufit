# Clufit — Admin

Panel administrativo de Clufit (Next.js + TypeScript + Tailwind CSS + shadcn/ui). Uso exclusivo del equipo de Clufit — no es utilizado por los usuarios finales.

La especificación de producto vive en [`/docs`](../../docs), [`/modules`](../../modules), [`/systems`](../../systems) y [`/contracts`](../../contracts) en la raíz del repositorio.

## Desarrollo

```bash
npm install
npm run dev
```

Abrí [http://localhost:3000](http://localhost:3000).

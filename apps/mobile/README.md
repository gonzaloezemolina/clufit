# Clufit — Mobile

Aplicación móvil de Clufit (React Native + Expo + Expo Router + NativeWind + React Query + Zustand).

La especificación de producto vive en [`/docs`](../../docs), [`/modules`](../../modules), [`/systems`](../../systems) y [`/contracts`](../../contracts) en la raíz del repositorio.

## Desarrollo

```bash
npm install
npx expo start
```

- `npm run ios` — simulador iOS (requiere macOS).
- `npm run android` — emulador Android.
- `npm run web` — versión web de Expo.
